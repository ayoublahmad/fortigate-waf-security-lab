# FortiGate WAF DVWA Security Lab

Documentation and working files for deploying, configuring, testing, and reporting on a FortiGate WAF security lab protecting DVWA.

## Project structure

- `docs/` - Architecture, deployment, testing, and final report documentation
- `configs/` - FortiGate, Nginx, ModSecurity, Wazuh, and Docker configuration files
- `scripts/` - Automation and operational scripts
- `evidence/` - Sprint-by-sprint screenshots, logs, and supporting evidence

## Project status

Project documentation scaffold created. Deployment and test details will be added incrementally.
